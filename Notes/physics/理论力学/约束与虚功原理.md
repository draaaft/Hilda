## 约束与广义坐标

对有约束系统：矢量力学（牛顿力学）分析：

$$m_i \ddot{x}_i = F_i^e + \sum_j F_{j \to i}$$

*(其中 $F_i^e$ 为外力，$\sum_j F_{j \to i}$ 为内力)*

$$f_m(x_1, x_2, \cdots, t) = 0 \quad \text{完整约束}$$

- 是否含 $t$：
  - 是 — 稳定约束
  - 否 — 不稳定约束

无约束系统总自由度为 $3N$，即位置矢量 $\vec{x}$ 的总分量数。存在 $k$ 个完整约束的系统中，总自由度数 $f = 3N - k$，可引入 $f$ 个相互独立的广义坐标来求解问题。

$\to$ 学到这的练习题是：判断自由度值；判断约束类型；列所有约束方程。

## 虚功原理和达朗贝尔原理（d'Alembert's principle）

先考虑处于力学平衡的，有约束的力学系统。考虑在某时刻位（满足运动方程和约束条件）的一个小虚位移 $\delta x_i$，[状态空间] 因力平衡：

$$\sum_i F_i \cdot \delta x_i = 0$$

其中 $F_i$ 为所有的力，现在将它分为约束力 $F_i^c$ 和主动力 $F_i^a$：

$$F_i = F_i^a + F_i^c$$

[假设] $\sum_i F_i^c \cdot \delta x_i = 0$ $\implies$ 意为约束力与所有可能的轨迹垂直。

那么：

$$\sum_i F_i^a \cdot \delta x_i = 0$$

如果力学系统并非力学平衡态，那么将 $F_i = 0$ 替换为 $F_i - \dot{p}_i = 0$

即：

$$\sum_i (F_i^a - \dot{p}_i) \delta x_i = 0$$

这与惯性力的思路也是一致的。

1> 因为有约束，即物体的空间状态是有限的，故有可能取 $[F_i^a - \dot{p}_i]$ 垂直于 $\delta x_i$，故 $F_i^a - \dot{p}_i$ 不一定为零。

问题：回到假设先，假设是

$$\sum_i F_i^c \cdot \delta x_i = 0$$

那有没有可能 $F_i^c$ 不时刻垂直 $\delta x_i$，而是有正负抵消了。

谜底： 别忘了研究对象是同一时刻，同一时刻所有约束力所做虚功和为零，也就是时时为零的意思，但的确不一定处处为零，比如相互作用力，可以一正一负抵消。

### 1. 完整约束 与 非完整约束 (Holonomic vs. Non-holonomic)

这是分析力学中最重要的一种分类，主要依据是**约束方程的数学表达形式及其可积性**。

- **完整约束 (Holonomic Constraints)**
    
    - **定义**：可以表示为系统各质点坐标（也可以显含时间）的**有限等式**的约束。即使约束方程最初含有速度（一阶导数），只要该方程能**积分**还原成坐标的有限等式，它依然是完整约束。
        
    - **数学形式**：
        
        ```
        f(q1,q2,…,qn,t)=0f(q1​,q2​,…,qn​,t)=0
        ```
        
        （其中
        
        ```
        qiqi​
        ```
        
        是坐标，
        
        ```
        tt
        ```
        
        是时间）。
        
    - **特点**：每一个完整约束都会**直接减少系统的一个独立自由度**。
        
    - **例子**：
        
        - 长为
            
            ```
            LL
            ```
            
            且不可伸长的单摆（
            
            ```
            x2+y2−L2=0x2+y2−L2=0
            ```
            
            ）。
            
        - 限制在固定球面上的质点（
            
            ```
            x2+y2+z2−R2=0x2+y2+z2−R2=0
            ```
            
            ）。
            
- **非完整约束 (Non-holonomic Constraints)**
    
    - **定义**：不能表示为坐标和时间的有限等式约束。它们通常是包含系统速度且**不可积分**的微分约束，或者是包含不等式的约束。
        
    - **数学形式**：如
        
        ```
        ∑Aiq˙i+B=0∑Ai​q˙​i​+B=0
        ```
        
        （不可积），或者
        
        ```
        f(q1,q2,…,qn,t)≥0f(q1​,q2​,…,qn​,t)≥0
        ```
        
        。
        
    - **特点**：非完整约束限制了系统的**运动方向或路径**，但**不减少系统可能达到的空间位形数量（不减少自由度）**。处理非完整系统不能直接用标准的拉格朗日方程，需要引入拉格朗日乘子法或其他特殊方程。
        
    - **例子**：
        
        - **纯滚动问题**（最经典的非完整约束）：如硬币在粗糙桌面上滚动而不滑动。其瞬时接触点的速度必须为零，这是一个关于速度的微分约束，且无法积分转化为坐标的约束（硬币可以滚到桌面的任意位置，位形不受限制，但怎么滚过去的路径受限制）。
            
        - **单面约束**（如气体分子被限制在容器内
            
            ```
            x2+y2+z2≤R2x2+y2+z2≤R2
            ```
            
            ）。

### 2. 理想约束 与 非理想约束 (Ideal vs. Non-ideal)

这种分类的依据是**约束力是否在虚位移上作功**。这是达朗贝尔原理和建立拉格朗日力学的基础。

- **理想约束 (Ideal Constraints)**
    
    - **定义**：在系统的任何**虚位移**（符合约束条件的无限小假想位移，记为
        
        ```
        δrδr
        ```
        
        ）中，所有约束力对系统所作的**虚功之和等于零**。
        
    - **数学形式**：
        
        ```
        ∑iFci⋅δri=0∑i​Fci​⋅δri​=0
        ```
        
        （
        
        ```
        FciFci​
        ```
        
        为第
        
        ```
        ii
        ```
        
        个质点受到的约束力）。
        
    - **特点**：由于约束力不做虚功，在建立分析力学方程时，可以**直接将未知的约束力消去**，只考虑主动力（如重力、弹簧力）。这使得求解力学问题极为大简化。
        
    - **例子**：
        
        - 绝对光滑的表面或轨道（约束力/法向支持力与虚位移垂直，做功为零）。
            
        - 刚体内部各质点间的相互作用力（内力相互抵消做虚功为零）。
            
        - 不可伸长的轻绳、无摩擦的铰链。
            
        - 注意：纯滚动虽然是非完整约束，但它通常是理想约束，因为接触点在发生虚位移时相对静止，静摩擦力不做虚功。
            
- **非理想约束 (Non-ideal Constraints)**
    
    - **定义**：约束力在系统的虚位移上作的虚功之和不为零。
        
    - **数学形式**：
        
        ```
        ∑iFci⋅δri≠0∑i​Fci​⋅δri​=0
        ```
        
        。
        
    - **特点**：不能直接从虚功原理中消去，通常是因为存在耗散力。
        
    - **例子**：
        
        - **粗糙表面上的滑动**（滑动摩擦力与虚位移方向相反，作负功）。
            
    - **处理方法**：在分析力学中，遇到非理想约束时，通常将摩擦力等非理想约束力视为“主动力”加入方程，或者通过瑞利耗散函数（Rayleigh dissipation function）来修正动力学方程。
